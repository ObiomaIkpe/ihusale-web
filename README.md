# ihusale-web

Marketing site for [IhuSale](https://ihusale.com.ng): the landing page, Privacy Policy and Terms of Service.

Plain HTML and CSS with no build step. Open `index.html` in a browser to preview.

## Deploy

Hosted on Vercel. Every push to `main` deploys automatically. The domain `ihusale.com.ng` points here through DNS records set at WhoGoHost.

## Files

- `index.html`: landing page
- `styles.css`: shared styles; colours match the IhuSale Figma styles
- `favicon.svg`: site icon
- `privacy.html`, `terms.html`: legal pages (in progress)
